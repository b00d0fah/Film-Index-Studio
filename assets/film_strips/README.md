# 自定义胶片模板

软件从 EXE 同级的 `templates/` 文件夹读取模板。每个模板为一个子文件夹，软件中显示的名称就是文件夹名称。

示例：`templates/我的胶片/1-6.png`。

每个文件夹必须包含以下七张 PNG，每张尺寸必须是 **4502 × 700 像素**：

`1-6.png`、`7-12.png`、`13-18.png`、`19-24.png`、`25-30.png`、`31-36.png`、`37-42.png`。

每张条带容纳六张照片。第一个照片窗口从 `(26,110)` 开始，大小 `720 × 480`，每格横向步进 746 像素。齿孔由内置资源叠加；模板可以使用透明 PNG。可复制软件附带的模板文件夹，以此替换图案。

导入方式：

1. 在软件的“排版”页点“导入模板”，选择上述文件夹；会检查所有图片，复制后立即选中。
2. 直接把模板子文件夹复制到 `templates/`，在软件中点“刷新”。不要把七张图片直接放在 `templates/` 根目录。

已有同名模板不会被导入按钮覆盖。手工替换同名文件夹将优先于内置同名模板；预设会保存所选模板副本，因此已有预设不依赖外部模板继续存在。

标准模板仍保持 135 六格结构；本版本不支持任意窗格数量或不同的照片窗口几何。
